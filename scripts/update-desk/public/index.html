Local Update Desk

Solar Dinosaur

Upload Excel workbooks with new building data. The desk detects what each file contributes (kWh, rates, or addresses), lets you review summaries and key edits, then updates the repo and live site.

  1. Unlock
  2. Upload
  3. Review
  4. Apply
  5. Publish

1. Unlock

Enter the shared password from .env.update-desk.

2. Upload & process

Drop any-named .xlsx files. Contents decide the type: year-sheet energy data, Elec/CS rates savings workbook, or building addresses.

3. Review

Check what each file contributes. Edit display names and key Elec / CS rates if needed. Fix kWh or addresses in Excel and re-process if those look wrong.

Place buildings on the map

These buildings are in the Excel data but have no map position yet. Enter a street address for each, then click Place on map (geocodes and projects markers).

Archives previous source files, saves your name/rate edits, and rebuilds the runtime data the website uses.
